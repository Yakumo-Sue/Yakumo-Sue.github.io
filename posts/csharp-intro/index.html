C# 入门

C# 学习系列： C# 入门 → C# 基础 → C# 进阶 → C# 高级

从第一个控制台程序开始，学习变量、常量、类型转换、异常、运算符、分支与循环，最后完成控制台小游戏《拯救公主》。

面向零基础读者。配套项目使用 .NET 10，代码采用 C# 12 及以前已有的语法；不依赖第三方包。正文用中文讲解，游戏画面使用单列宽度的英文字符，避免不同终端的中文、表情宽度导致地图错位。

阅读与运行约定

  1. 按章节顺序学习。前九章中的短代码通常是相互独立的片段，放进第一章的 Main 方法中运行；不要把全部片段连续粘贴到一个方法中，否则可能出现同名变量重复声明。

  4. 第一遍可以先记住 int、float、double、bool、char、string；object、dynamic、位运算和可空类型理解用途即可。
  5. 前九章的游戏相关例子是逐项练习；第十章提供整合后的完整代码、运行步骤、玩法和验收清单。

1.1 C#、.NET 与控制台是什么

C# 是编程语言，.NET 提供运行程序所需的运行时和类库，.NET SDK 提供创建、编译和运行项目的开发工具。

2.4 有符号与无符号整数

“有符号”表示能存储负数、零和正数；“无符号”只能存储零和正数。同样的位数下，无符号整数把全部取值空间用于非负数。

1 byte = 8 bit。这里的 byte 是存储单位“字节”，C# 中的 byte 则是一个具体类型。

int 4 是 -2,147,483,648 2,147,483,647

long 8 是 -9,223,372,036,854,775,808 9,223,372,036,854,775,807

日常计数、坐标和血量优先使用 int。不能仅因为“血量不应该是负数”就一律选择 uint：减法、边界计算和不同整数类型混合时，int 更容易处理。

L、U、UL 是整数字面量后缀；_ 可以用于分隔数字，提高可读性，不改变数值。推荐用大写 L，避免小写 l 与数字 1 混淆。

补充了解：nint、nuint 是本机大小整数，在 32 位进程中为 32 位，在 64 位进程中为 64 位，常用于底层互操作。本教程不需要它们。整数类型说明

第四章：转义字符

4.1 为什么需要转义

普通字符串使用双引号作为边界。如果内容本身也要有双引号，或要包含换行、制表符，就需要特殊写法。

普通字符串中的反斜杠 \ 用来引入转义序列。源代码里的两个字符 \n，在字符串中表示一个换行控制字符。

执行顺序：

  1. 先执行 try。
  2. 若没有异常，跳过各个 catch。
  3. 若某句抛出异常，try 中它后面的语句不再继续执行，寻找第一个匹配的 catch。
  4. 有 finally 时，在正常控制流离开这组结构前执行它，包括通过 return 离开的情况。
  5. 若异常没有被处理，它会继续向调用方传播。

finally 常用来恢复状态或释放资源；不能把它理解成“无论操作系统强制结束进程还是断电都一定执行”。异常处理说明

10.6 先搭出关键算法

一、移动前先计算目标位置，不要先改坐标再想办法撤回。

10.10 为什么这样处理几个细节

保持画面固定。 每一行统一为 72 个英文字符宽度，每次先把光标移回 (0, 0)，再输出完整画面，不在每次按键后都 Clear()。这样可减少清屏带来的闪烁，也不会把不断增长的战斗文字写到地图下面。

最后一行不额外换行。 终端最后一行的换行可能导致整体滚动，因此 Draw 只在各行之间插入换行符。

显示的是实际扣血。 如果怪兽只剩 3 点血量，随机攻击值是 20，实际伤害显示为 3，血量变为零，不显示负数。

死亡判定立即结束相关流程。 怪兽死亡后 return，本回合不再反击；玩家死亡后切换结束场景，下一轮主循环便不再处理游戏移动。

护送必须显式触发。 击败怪兽只会生成公主，不会自动把她变成跟随状态；需要相邻再次按空格。这样救援与护送两个阶段能够清晰区分。

每局重新设置全部状态。 R 重新开始时，双方恢复 100 点血量，回合清零，护送与胜负标志复位，旧出口和旧日志清除，玩家重新随机出生。

恢复终端状态。 程序通过 finally 恢复光标显示并重置颜色。终端在绘制瞬间缩小时仍可能报告坐标异常，程序会提示调整后重新运行。

10.11 实际游玩步骤

  1. 调整终端到至少 73 列 × 33 行，运行程序。
  2. 在开始场景按回车，找到代表玩家的 H 与固定位置的 M。
  3. 用 WASD 移动到 M 的上、下、左或右侧。
  4. 按一次空格，查看下方玩家攻击与怪兽反击的记录。继续按空格，直到一方血量归零。
  5. 如果失败，在结束场景按 R 开始新一局。
  6. 如果获胜，M 的位置显示为 P，地图其他空地显示 E。
  7. 保持与 P 相邻，按空格，状态栏目标变为 ESCORT P TO E。
  8. 向 E 移动，观察 P 始终跟在上一格。走到出口后进入胜利场景。

两边伤害均随机，玩家有先手优势但不保证每局必胜。这使失败场景也具有实际意义。
